# 1inch Smart Contract Audit Reports

## Overview

This folder contains public smart contract audit reports and audit certificates for **1inch**, one of the most established DeFi aggregation protocols.

Softstack completed **multiple security audit engagements for 1inch** across different protocol components, product releases, and contract versions. This folder reflects a **recurring audit relationship** rather than a single one-time review.

## About 1inch

**1inch** is a DeFi aggregation protocol that helps users execute token swaps across multiple liquidity sources and routing paths. The broader 1inch ecosystem includes swap aggregation, limit order functionality, RFQ based routing, and token-related infrastructure.

As one of the better known names in decentralized trading infrastructure, 1inch is a strong reference case for audit work involving exchange logic, routing systems, order execution, and token distribution contracts.

## Why This Project Matters

Auditing 1inch-related smart contracts is important because routing, aggregation, exchange execution, and order infrastructure are all highly security-sensitive areas of DeFi.

This folder is a strong public example of Softstack's experience in:

- DeFi smart contract audits
- DEX and aggregation protocol security
- limit order protocol security
- routing and RFQ infrastructure reviews
- recurring security work for an established Web3 protocol
